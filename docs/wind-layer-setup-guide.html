🌬️ 风场图层开启图文教程

目标：给 HurricaneHub 雷达页的「Wind（地面风场）」图层配上数据。全程约 5–10 分钟，不需要写代码。

为什么要做这一步？
雷达页已经有 4 个图层（Rain / Satellite / Forecast / Wind）。其中前三个已经能直接用； 唯独 Wind 需要一张「风的瓦片地图」，数据源是 OpenWeatherMap，要用一个免费 API Key 才能出图。 不配也能正常用网站，只是 Wind 图层会提示「需要配置 Key」——配了之后就能看到实时风场。

二、详细步骤

第 1 部分：拿 OpenWeatherMap 的 Key

1
打开注册页：
https://home.openweathermap.org/users/sign_up
填 邮箱 和 密码，点 Create account。
2
去你的邮箱，找到 OpenWeatherMap 发来的验证邮件，点里面的确认链接激活账号。
没收到？检查垃圾邮件箱；或等 1–2 分钟再刷新。
3
登录后，打开 API Key 页面：
https://home.openweathermap.org/api_keys
页面上会有一条叫 Default 的 Key（一长串字母和数字）。
点它右边的 复制（Copy） 按钮，把 Key 存到备忘录里。
示意图：API Keys 页面（红框处就是你要复制的 Key）
新注册的 Key 偶尔要等几分钟到几小时才生效（OWM 激活延迟）。如果第 4 步配完后风场还是 401， 先放一放，过 1–2 小时再试，不用怀疑自己配错了。

第 2 部分：把 Key 配到 Cloudflare

4
打开 https://dash.cloudflare.com 并登录 （就是你部署 HurricaneHub 时用的那个 Cloudflare 账号）。
5
左侧菜单点 Workers & Pages（中文界面叫「Workers 和 Pages」）， 在列表里找到名为 hurricanehub 的 Worker，点进去。
6
点顶部标签页里的 Settings（设置）， 往下滚找到 Variables and Secrets（环境变量与密钥）这一块。
7
点 Add / Add variable（添加变量），填两项：
名称 (Variable name)值 (Value)
OPENWEATHER_API_KEY刚才复制的那串 Key
类型选 Text / Variable（明文变量） 即可；想更稳妥可以选 Secret（加密）。
填完点 Save / Deploy 保存。
示意图：Variables 添加界面
⚠️ 重要（很多人卡在这）：这个 Worker 是用命令行 wrangler deploy 部署的， 在 Dashboard 里加的变量经常不会被正在跑的 Worker 读取到。两个可靠做法（二选一）：

做法 A（推荐，最稳）：用终端写入加密密钥，写的同时会自动重新部署。
在你电脑的「终端」里依次粘贴执行（首次会弹浏览器让你登录 Cloudflare，点允许）：
cd /Users/canbao1/Documents/hurricanetracker
npx wrangler login
npx wrangler secret put OPENWEATHER_API_KEY --config wrangler.deploy.toml
终端提示 Enter a secret value: 时，粘贴你的 OWM Key 并回车
执行完会自动部署，无需再手动 deploy。

做法 B（已用 Dashboard 加过的，补一步）：回到终端执行 npx wrangler deploy --config wrangler.deploy.toml 重新部署一次，让变量打包进 Worker。 如果重新部署后点 Wind 仍提示需要 Key，说明 Dashboard 的变量没被采纳，请用做法 A。

三、验证是否成功

8
打开 https://www.hurricanetracker.cc/radar/， 点左下角图层栏里的 Wind 按钮。
成功标志：地图上出现一层半透明的风的箭头/色块（风速与风向）。
如果还是提示「需要配置 Key」或一片空白：先确认变量名是 OPENWEATHER_API_KEY（大小写、下划线别拼错）， 再确认 Key 已复制完整，最后等 1–2 小时（OWM 新 Key 激活延迟）后刷新重试。

四、常见问题

现象原因 / 解决
点了 Wind 还是「需要配置 Key」 变量名拼错（必须是 OPENWEATHER_API_KEY），或还没保存成功。回去第 6–7 步核对。
风场 401 / 403 错误 OWM 新 Key 未激活，等 1–2 小时再试；或 Key 复制不完整。
风场一直空白但不报错 该区域当时无风场数据（罕见）。换到飓风活跃区（如墨西哥湾、大西洋）再看。
不配 Key 会影响其他功能吗 不会。Rain / Satellite / Forecast 三个图层完全独立，照常使用。
本教程对应 HurricaneHub 代码：风场经 /api/wind/* 代理转发至 OpenWeatherMap wind_new 图层，Key 仅存于服务端，不会暴露到浏览器。
